# Security Policy

Do not report vulnerabilities through public issues. Send a private report to the project maintainer with reproduction steps, impact, affected version, and a proposed mitigation when available.

The team acknowledges reports, assesses impact, prepares a fix, and coordinates disclosure after a remediation is available.
