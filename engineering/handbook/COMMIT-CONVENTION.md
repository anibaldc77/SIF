# Commit Convention

SIF uses Conventional Commits:

`feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, and `revert`.

Use the form `type(scope): imperative summary`. Keep commits atomic, scoped to one Work Package where possible, and include tests and documentation with behavioral changes.
