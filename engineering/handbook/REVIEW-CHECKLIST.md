# Review Checklist

- [ ] Change is within the approved Work Package scope.
- [ ] Public APIs and architectural boundaries are preserved.
- [ ] Tests cover changed behavior.
- [ ] Documentation, changelog, and implementation report are current.
- [ ] Composer metadata and component metadata are valid.
- [ ] Quality Gate passes locally and in CI.
- [ ] No secrets, vendor files, caches, or generated artifacts are tracked.
