# Governance

The Chief Software Architect owns architectural direction, specifications, ADR approval, releases, and protected-branch policy. Maintainers review contributions against the approved Work Package, Quality Gate, and public API compatibility requirements.

Technical disagreements are resolved through evidence, the SIF Architecture Specification, and ADRs. The `main` branch remains protected and integrable.
