# Contributing to SIF

Thank you for contributing. Review the [Engineering Handbook](engineering/handbook/HANDBOOK.md) before opening work.

1. Create a branch using the approved naming strategy.
2. Keep each change scoped to its Work Package.
3. Run `composer quality` and update documentation and the implementation report.
4. Use Conventional Commits and open a pull request with the provided template.

Contributions must preserve public API compatibility unless an approved specification or ADR explicitly authorizes a change.
